## ADDED Requirements

### Requirement: Profile picture upload URL can be requested
The system SHALL allow an authorized caller to request a temporary upload URL for a customer's profile picture using image metadata.

#### Scenario: Upload URL request succeeds
- **WHEN** an authorized admin requests an upload URL for an existing customer with valid image metadata
- **THEN** the system responds with an upload URL, blob URL, blob name, expiration timestamp, and required upload method.

#### Scenario: Customer is missing
- **WHEN** an authorized admin requests an upload URL for a customer ID that does not exist
- **THEN** the system responds with a not found error.

### Requirement: Profile picture upload metadata is validated
The system SHALL validate profile picture upload metadata before generating a storage URL.

#### Scenario: Unsupported image type is rejected
- **WHEN** a caller submits metadata with a content type other than JPEG, PNG, or WebP
- **THEN** the system responds with a validation error and does not generate an upload URL.

#### Scenario: Oversized image is rejected
- **WHEN** a caller submits metadata with a file size larger than the configured maximum
- **THEN** the system responds with a validation error and does not generate an upload URL.

### Requirement: Storage integration supports missing Azure credentials
The system SHALL continue to build, start, and test when Azure Blob Storage credentials are not configured.

#### Scenario: Azure credentials are absent
- **WHEN** the service starts without an Azure Blob Storage connection string
- **THEN** dependency injection registers a local fallback storage implementation instead of failing startup.

#### Scenario: Fallback upload URL is returned
- **WHEN** a valid upload URL request is handled while Azure Blob Storage is not configured
- **THEN** the system returns a deterministic local placeholder upload URL and blob URL without contacting Azure.

### Requirement: Azure Blob Storage signed upload URLs are generated
The system SHALL generate signed Blob Storage upload URLs through Azure Blob Storage when valid storage configuration is present.

#### Scenario: Azure storage is configured
- **WHEN** Azure Blob Storage connection string and container name are configured
- **THEN** the storage implementation generates a time-limited upload URL for the generated blob name.

#### Scenario: Blob name is server-generated
- **WHEN** a caller requests an upload URL
- **THEN** the blob name is generated by the service under a customer-specific profile picture path.
